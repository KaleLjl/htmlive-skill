# htmlive

Agent skill for 页享 · HTMLive. It tells an agent when to use HTMLive, which template to pick, and how to publish HTML the caller already wrote.

Installing this skill copies these instructions only. It does not connect the HTMLive MCP server, sign anyone in, or connect every host. The skill file gives the public MCP address when the tools are missing.

```bash
npx skills add KaleLjl/htmlive-skill
```

The skill directory is `skills/htmlive/`. There is no `SKILL.md` at the repository root.
